a little about the way I work

I care less about clever code, and more about systems people can simply depend on.

Data comes first

An API is only as good as the schema underneath it. I design the data model, the indexes, and the failure cases before I write the first endpoint.

Root cause, not patches

A bug fixed twice was never fixed. When production misbehaves, I dig until I find the actual cause — then make that class of failure impossible.

Built to hold under load

Transactions that stay atomic, queries that scale with the data, logs that tell the truth. Boring reliability is the feature nobody thanks you for — until it's gone.
